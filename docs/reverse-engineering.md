# 設計リバース

システム権限者（権限 `0`）でログインし、業務メニューの「設計リバース」から開きます。画面は読み取り専用です。権限 `1`・`2` のユーザーは画面とデータ取得 API の両方にアクセスできません。

-   **DB リバース**: 接続中の MySQL データベースからテーブル・列・主キー・外部キーを取得し、選択したテーブルの関係図と定義一覧を表示します。行データは取得しません。
-   **Java リバース**: 配備済み WAR の`jp.nw`クラスを調べ、クラスの型、フィールド、公開メソッド、継承・実装・型参照の関係図を表示します。ソース本文は取得しません。
-   検索と JSON 保存を利用できます。JSON 保存も権限 `0` のログイン中に読み取った構造のみを対象にします。

関係図は、選択した項目から直接つながる最大 8 項目を表示します。全関係は図の下の一覧で確認できます。DB の外部キーが定義されていない列や Java メソッド本体内の呼び出し関係は推測しません。
