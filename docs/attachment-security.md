# 添付ファイルのセキュリティ

## 権限

- 報告書: 作成者だけが下書き・差戻し中にアップロードできます。閲覧は作成者と承認権限者に限定します。
- チャット: 有効なチャットルームの参加者だけがアップロード・ダウンロードできます。
- 予定: 所有者だけがアップロードできます。閲覧は所有者、共有予定のユーザー、招待された参加者に限定します。
- 承認: 申請者だけがアップロードできます。閲覧は申請者と承認権限者に限定します。

権限のないダウンロード要求は、ファイルの存在を推測されないよう404を返します。

## 許可するファイル

最大サイズは10MBです。許可する拡張子は次のとおりです。

`pdf`, `png`, `jpg`, `jpeg`, `gif`, `txt`, `csv`, `zip`, `docx`, `xlsx`, `pptx`

ブラウザが送信したMIMEタイプだけでは判定せず、拡張子、MIMEタイプ、ファイルシグネチャを照合します。
保存名には利用者が入力した名前を使わず、UUIDを使用します。

## ウイルススキャナーの追加

`jp.nw.model.AttachmentVirusScanner`を実装し、Javaの`ServiceLoader`へ登録します。
実装クラスの完全修飾名を次のファイルへ記載してください。

`META-INF/services/jp.nw.model.AttachmentVirusScanner`

スキャンは一時ファイルに対して実行されます。`ScanResult.rejected(...)`を返したファイルは、正式な保存先やDBへ登録されません。
スキャナー実装が登録されていない環境では、組み込みのNo-Op実装が使用されます。
